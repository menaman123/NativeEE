# BUG-084 — TEX1.K read as an unsigned 12-bit field: every mip-mapped draw with a negative LOD bias sampled its COARSEST authored level (the title's logo letters a flat dirty yellow, the orb's additive arcs dim, the ocean's specular layer gone) (FIXED)

| Field | Content |
|---|---|
| **ID** | BUG-084 |
| **Title** | `DrawFlush::FillTexture` copied the TEX1 register's raw 12-bit K field into the draw's `TexReadView.k` (`t.k = static_cast<int16_t>(c.tex1.k)`), while K is a SIGNED s7.4 LOD parameter (GS User's Manual 3.4.12: LOD = (log2(1/\|Q\|) << L) + K). A title bias of −4.3125 (TEX1 `0xffffffbb00000128`, K = 0xfbb) became +251.69, so the shader's retail LOD term (`u_mip_lodp.x`) pushed every mip-mapped read to `min(lod, MXL)` = the coarsest authored level. The logo letters' UVs all fall inside the atlas's flat yellow swatch; at level 2 (8x8) that swatch is one blended texel — the letters came out ONE flat colour (116,100,37) × the ×255>>7 modulate = (231,199,73), a colour no CLUT holds (BUG-081's "computed colour"). The orb (K −4.31, MXL 2) and the ocean specular (K −7.5, MXL 4) textures likewise sampled 8x8 / 8x8-of-128 levels: dim, blurred, below the bright threshold |
| **User-visible symptom** | "Orb additive effects missing, logo washed out, ocean specular highlights missing" (user, 2026-10-04); every scene's mip-mapped textures with a negative K (most of the title's world textures carry K < 0) rendered one or more levels too coarse |
| **Scene / savestate** | cold boot 2520 frames (deterministic profile), frame 2519 (the title); before: LOGO yellow (213,177,65) bright 0.182 / ORB bright 0.098 / OCEAN bright 0.472; after: (238,215,14) 0.635 / 0.443 / 0.701 vs the console (238,216,16) 0.605 / 0.417 / 0.659 (`int_work/p824a/live_rel_regions.txt`) |
| **Subsystem** | `gs-texsrc` (the draw's texture view: `engine/gs/state/draw_flush.cpp`; sampled by `gl_shader_sources.cpp` `[S82-MIP]`); sec. `gs-classes` |
| **Root cause** | `GsRegisters::Tex1::k` keeps the raw register field (`(v >> 32) & 0xFFF`, correct for a register mirror and for the savestate); the ONE conversion into the draw's signed `TexReadView.k` (`DrawFlush::FillTexture`) did not sign-extend it. Every consumer downstream trusted the s7.4 contract the header states (`int16_t k; // LOD bias, s7.4`): `MipSampler::Capture` copies it into the chain, `GlDrawExecutor` writes `u_mip_lodp.x = k / 16`, the shader adds it to log2(1/\|Q\|). The replay harnesses (`test_title_frame_replay`, `test_title_logo_draw`) build their views from the dump's registers with their own sign-extending `ViewFromRegs`, which is why the dump's frame rendered correctly through the same pipeline while the live run did not — the ONLY live-only difference was the sign of K. OLD sign-extended it (`host_app/gs_mipmap.h:252-254`: "Sign-extend the 12-bit s7.4 K field") |
| **PS2 rule violated** | GS User's Manual 3.4.12 (LOD setting): TEX1.K bits 43:32 is a signed 12-bit fixed-point value (1:7:4), LOD = (log2(1/\|Q\|) << L) + K, clamped to [0, MXL]; a negative K selects a finer level |
| **Fix + hatch** | `engine/gs/state/draw_flush.cpp` `FillTexture`: `t.k` = the sign-extended field (bit 11 → −0x1000). No toggle: a construction gap (the code now matches the GS rule, the header's contract and OLD); the register mirror and the savestate keep the raw field unchanged |
| **Regression test** | `Gs_Inv40_Tex1KSignExtended` (RED before: `K 0xfbb is -69 (s7.4 = -4.3125)` and `K 0x800 is -2048` FAIL, `test_gs_state inv40: 5 checks, 2 failures`; GREEN after), the live gate `RootTitleScreenEffects` (Release coldboot 2520 → f2519's three regions vs the console; RED on the pre-fix frame — three FAIL lines — PASS after), `Render_TitleLogoDrawPin` now carries the dump's MIPTBP1 chain (levels 1–2 at 0x3c0800 / 0x3c0a00), `RootPlayPolicyInert` unchanged (the first 130 coldboot frames have no negative-K mip read) |
| **Source record** | `docs/phases/PHASE8_IMPL.md` §P8.24-A (`int_work/p824a/`: the TexresTrace records `live_diag/frames/texres_f2519.txt`, `live_diag2/frames/texres_f2519/d1770125_tex.ppm`, `trace_summary_f2519.txt`, `synth_levels.py`, `gsf1_mip.py`, `live_rel_regions.txt`, `gate_prefix_red.log`, `gate_postfix_green.log`) |
| **Triage tips** | a texture that renders as ONE flat colour, or blurred, only in the live run while the dump replay is right → read the draw's `TexReadView` against the register: the `TexresTrace` (`<dump-frames dir>/texres_trace.cfg`, diagnostics builds) prints `TEX1(mxl lcm l k)` per read — K must be negative for a negative bias (−69 for 0xfbb). `MipSampler::SignExtendK` exists for raw fields; the s7.4 value is what a `TexReadView` carries.
