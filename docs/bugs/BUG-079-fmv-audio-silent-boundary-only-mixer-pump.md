# BUG-079 — FMV audio silent: the mixer pumped only at EE frame boundaries mixes the movie's PCM after the title zeroed BVOL

| Field | Content |
|---|---|
| **ID** | BUG-079 |
| **Title** | FMV audio silent — the movie's PCM reaches the mixer but is mixed only at EE frame boundaries, none of which pass during the movie, so it is consumed after the title's end-of-movie `BVOL = 0` |
| **User-visible symptom** | "I hear no sound from the FMV" (2026-10-04): both intro movies play with picture and no audio in play mode; the device also starves (underruns) during movies and loads |
| **Scene / savestate** | cold boot through the two intro movies (play mode `--frames 200`, `fmv_window=154-167`); the console reference `crash_tt_save_states/start_button_before_fmv.p2s` + `frame_advance` into the movie |
| **Subsystem** | `iop-sound` (primary), `ee-timing` (secondary) |
| **Root cause** | The title's own EE code programs the SPU2 core-0 external-input volume at movie start: `FUN_002ae318` (movie-audio start) → `FUN_002af458(1.0)` → `sceSdRemote(1, 0x8010, 0xF80, 0x7FFF)` and `(…, 0x1080, 0x7FFF)` (BVOLL/BVOLR), and back to 0 at movie end. NEW's libsdr row forwards both to `SpuCore::SetParam` → `core_param_shadow_[0][0xF/0x10]` (the SDK encoding `core | (param << 8)`, bit 7 = core attribute, decodes to the right indices). But the mixer (`Mixer::Pump` → `SpuCore::MixInto`, where the FMV PCM is added at the BVOL gain) ran only in the boundary sequencer's Verify slot; a movie spans ≈1100 display fields during which the EE passes no frame boundary (the libmpeg pace park advances the domain tick only), so the first pumps that popped the queued PCM ran after the title had already written `BVOL = 0`: `mixed_audible=0` while `bvol_peak=0x7fff`. The earlier attribution "the title never programs BVOL" read the shadow at frame 400, after the end-of-movie zero. |
| **PS2 rule violated** | The SPU2 mixes 48 000 frames/s on its own clock; the core's external input enters the output at BVOLL/BVOLR continuously, independent of the EE's frame loop. A mixer clocked by EE frame boundaries stops the SPU2 whenever the EE does not pass one. |
| **Fix + hatch** | `app/host/ee_bootstrap.cpp`: in play mode the mixer is pumped once per DOMAIN TICK (display field) — the boundary's own hashed pump covers its tick, every display tick (FMV pace park field, late serve, kernel timer wait, disc wait) catches up the fields the domain advanced, each 800-frame quantum pushed to the device ring only; the hash lane keeps exactly 800 frames per EE boundary. Hatch: `audio_field_pump_on` (one line; `false` = boundary-only pump). Census: `snd_pumps_fields=`, `fmv_pcm=…bvol_sets=,bvol_nonzero_sets=,bvol_peak=,mixed_audible=`, `audio_device=quanta=,nonsilent=` (`SpuCore::BvolSets/BvolSetsNonZero/BvolPeak/FmvFramesMixedAudible`). DECISIONS_LOG DP-29. |
| **Regression test** | `FmvPcmInput` (BVOL census + audible frames), `RootMixesFmvPcm` (`bvol_peak=0x7fff`, `bvol_nonzero_sets >= 2`, `snd_pumps_fields=0` deterministic), `RootPlayFmvPresents` (play leg: `mixed_audible > 0`, `snd_pumps_fields > 1000`, `audio_device nonsilent > 0`), `RootPlayPolicyInert` (deterministic lanes unchanged) |
| **Source record** | `docs/phases/PHASE8_IMPL.md` §P8.16-A (`int_work/p816a/`); `docs/phases/INTEGRATION_IMPL.md` §I7.2-A (the mixer-side rule) and §I7.1-A (the device ring); `docs/phases/DECISIONS_LOG.md` DP-29; OLD `host_app/sound/sound_core.cpp:772-786` (the gain rule and its "0x7FFF at FMV start" comment), `host_app/verify/verify_boundary.cpp:58-72` (OLD's boundary-only pump — the same defect, the baseline's silent FMV window: row `P7-FMV-BVOL-OLD-UNSET` proposed) |
| **Triage tips** | If an audio source is "mixed" but inaudible, check WHEN it was mixed relative to the gain writes (`bvol_sets` vs `mixed_audible`), not only the final gain; a shadow read at the leg's end hides a set-then-clear. If the device underruns while the EE parks (movie, load), count mixer pumps against domain ticks (`snd_pumps` + `snd_pumps_fields` vs `tick_thread=ticks=`) — the SPU2 runs per field, not per EE frame. |
