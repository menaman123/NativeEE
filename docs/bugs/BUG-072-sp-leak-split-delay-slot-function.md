| **PS2 rule violated** | MIPS calling convention: a function's `jr ra` sees the sp it was entered with; one `addiu sp,-0x10` in the delay slot pairs with one `addiu sp,+0x10`. On the console an sp below `0x70000000` would be a TLB refill exception (KUSEG `0x6fff…` is unmapped), so the retail walk never runs at that depth — the leak is NEW's generation artefact, not title behaviour. |
| **Fix + hatch** | LANDED (P8.9-A). *Discovery rule* (`Walker::in_delay_slot` + `eligible` in `functions.cpp`): an address whose preceding word is a branch/jump (any kind with a delay slot: conditional, likely, unconditional, j, jal, jr, jalr — not eret) is never promoted from a WEAK seed (prologue pattern, data pointer, code-constructed pointer); the seed is recorded in `DiscoveryResult::delay_slot_weak_rejected`. A STRONG seed (jal / jump-table / ELF entry) in a delay slot is kept (the hardware starts there when called) and reported (`delay_slot_strong_entries`; the ELF has one, `0x2d2180`, preceded by an unexecuted `jr ra` padding word). *Leader rule* (the leader sweep in `functions.cpp`): a branch's fall-through `pc+8`, a jal/jalr return site and an external jump-table target become leaders of the CONTAINING function (not only when inside the site's own function), so the emitted `switch (addr)` carries a case for every externally-entered address. Regenerated: `[v2] discovered 8807 functions, 177 jump-table sites, 8848 unreached gap words`, `[v2] delay-slot rule: 12 weak seed(s) rejected, 1 strong entry in a delay slot`; `FUN_00178470` is one function again (`case 0x178480: goto Label_0001`). Hatch: `tools/regen_from_frozen.sh --frozen-old` regenerates the pre-fix set from OLD's frozen binary for proofs/diffs. No runtime change. |
