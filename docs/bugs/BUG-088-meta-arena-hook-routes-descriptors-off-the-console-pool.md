# BUG-088 — The inherited META-ARENA hook routes the title's handle-heap descriptors to a host arena the console does not have (the page pool holds them on hardware: 385 descriptors in slab class 7)

| Field | Content |
|---|---|
| **ID** | BUG-088 |
| **Title** | `FUN_00181560(size ≤ 0x20)` calls from the title's pool-allocator code `[0x202000, 0x206000)` were answered from a 2 MB host arena at EE phys `0x02000000` (HOOK row `0x181560`, `games/<title>/hle/workarounds/{meta_arena,free_list_0x181560}.{h,cpp}`), so the record pool's `0x20`-byte descriptors, its `0x18`-byte compaction job and its `0xc`-byte deferred-op nodes never touched the title's page pool; on the console they are slab class-7 chunks |
| **User-visible symptom** | None on screen. In memory: the record pool's handle table and header hold `0x200xxxx` pointers where the hardware holds RAM pointers; slab class 7 holds 9 pages where the hardware holds 12; every page-pool page popped after the descriptors' pages sits at a different index than on the console — the page→class assignment of the pool was undecidable against the console while the routing was on (P8.29-B `INT-P829B-PAGES-NEITHER`) |
| **Scene / savestate** | Deterministic coldboot, boundary 120 (`int_work/p832a/leg_{on,off}/state_b120.ps2st`) against the PCSX2 image at the matched moment `int_work/p828a/pcsx2_rec159_ee.bin` (`0x323278 = 0x159`, boot-SM case 2) |
| **Subsystem** | `ee-mem` (secondary: `savestate` — the META section / HEAP tail carry the arena) |
| **Root cause** | An inherited original-tree workaround, not a title defect. OLD (`host_app/main.cpp:397-415`, `:3186-3256`, `hle_meta_arena.{h,cpp}`) routed the three node kinds out of the shared slab because a HOST-side free-list corruption ("when one is freed its slab memory was reused as game data while pool 0x31b138 still referenced it … the case-6 key overwrite") poisoned the title's descriptor chain; HOOK_RECLASSIFICATION §3.1 classifies that corruption as host-induced ("does not occur on retail/PCSX2 … the arena is itself a non-hardware invention"). NEW transplanted the hook verbatim because the frozen OLD baselines carry its observable, with a retirement gate ("match OLD's baselines with the arena disabled") that could never close. The title's own `FUN_00181560` is `FUN_002044f8(FUN_00181620(), size)` — the page-pool allocator — and NEW's model reproduces no corruption with the routing off (121-frame coldboot and a 61-frame resume of OLD's `old_b120` finalize with every allocator invariant held: free-flagged == free-list reach, `+0x4c` == free count, used == the live counter) |
| **PS2 rule violated** | `[title-idiom]` The title's compacting handle heap keeps its descriptors in the memory its own page pool vends (32 MB of EE RAM is all there is; `0x02000000` does not exist on the console). A host runtime that answers a guest allocation from memory outside the machine changes the guest's heap layout at every later allocation |
| **Fix + hatch** | Config `hle.meta_arena` (DECISIONS_LOG DP-31): `off` = `free_list_0x181560::InstallHooks(…, route_allocations=false)` installs only the free body (arena pointers of a restored OLD-written image are still freed in the arena; every other pointer falls through to the recompiled free), so `FUN_00181560` runs as recompiled; the arena's storage and the HEAP/META sections stay (an all-zero META and the empty-arena tail on a fresh run; OLD-written images restore as before). Default `on`: DP-31 REVERTED on the 13-leg gate vs S12 under one classes snapshot (P8.32-A review loop 1; coldboot b120 unbooked WORSE by 1,054 words, b60 by 4,495 — the residual is the −3-page shift of the objects hardware builds and NEW never builds (LEDGER P8.32-B (4), BUG-089), not the hook's); to be re-scored after that gap is modelled, the toggle kept |
| **Regression test** | `WorkaroundFreeListHook` (route_allocations=false → the free body only); `RootMetaArenaOff` (coldboot b120 with `off` vs the console image: `desc in RAM 385 / META 0`, every descriptor a USED `cls 7/32B` chunk, 12 class-7 pages, the console's first class-7 pages at NEW's indices; RED with `--arm on`); `Coretest_config` (the key's default and round-trip) |
| **Source record** | `docs/phases/PHASE8_IMPL.md` P8.29-B (the console measurement) and P8.32-A (`int_work/p832a/`: `desc_walk.out`, `page_diff.out`, `compare_{off,on}.txt`, `pin_{off,on}.log`, `attr_{on,off}.run.log`); DECISIONS_LOG DP-31; EQUIVALENCE_PLAN §7.1 row `P8-META-ARENA-OLD-HOOK` |
| **Triage tips** | A record-pool header whose chain head (`+0x50`) or free-list heads (`+0xc..+0x48`) hold `0x200xxxx` says the routing is on; the console's hold RAM pointers into the page pool. A page→class compare against the console that disagrees from the first class-7 pop onward while the object CONTENT sets agree is this routing (3 pages), not an allocation difference. `verify/relocate_compare.walk_pool` walks META descriptors only — it cannot walk an `off` image until it follows the chain wherever the descriptors live (`console_compare.walk_records` does) |
