# `docs/filemap/`

Every hand-written file of the frozen OLD tree mapped to its destination in this tree:
`INDEX.md` (386 rows → 602 files: destination, shape, flags, hacks), the nine
`FILEMAP_*.md` shards (per-file detail), `FLAG_LEDGER.md` (553 env-var rows with their
outcome NORM/SETTING/DIAG/TEST/DELETE/NEW), `HACK_LEDGER.md` (269 hack rows), and
`FLAG_PHASE_COUNTS.txt` — GENERATED by `tools/flag_phase_counts.py` from FLAG_LEDGER
(ctest `FlagPhaseCountsReproducible` fails when stale; regenerate with
`python3 tools/flag_phase_counts.py > docs/filemap/FLAG_PHASE_COUNTS.txt`), and
`settings_table.tsv` — GENERATED by `tools/gen_settings_table.py` (the Config schema in
machine form: key / type / peak / det / source_var / ledger, verified against FLAG_LEDGER's
SETTING rows and PHASE1_PLAN §3; its `# deterministic_fingerprint=` header is the ONE source
of the deterministic golden for `tests/core/test_config*.cpp` and `verify/battery.py`;
ctest `SettingsTableReproducible` + `Coretest_config_schema`; regenerate with
`python3 tools/gen_settings_table.py > docs/filemap/settings_table.tsv`).

Belongs: the file map, the ledgers, the generated tally and schema table. Does not belong: code, plans.
