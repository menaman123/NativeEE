# Port compatibility audit

2026-10-07. Independent, source-only audit for M0–M12. This is a selected
compatibility backlog, **not a claim that every OLD bug is covered or that the
current candidate passes regression**. No builds, tests, games or save files
were run or created for this audit. Concurrent workers' new files are treated
as implementation evidence only, not proof of an enabled or accepted cutover.

`OLD:` means the frozen, read-only
`$PS2R_OLD_ROOT/`.
`L:` abbreviates `OLD:docs/loop_state/`; every `L:file:line` below identifies
that exact document and starting line, with its named section providing the
scope. `T:` means local
`games/<title>/hle/`. Other paths are local.
OLD's `docs/bugs/README.md:1` points to this project's bug catalog; its separate
`docs/bugs/BUG-035.md` remains primary evidence for the event-drain hang.
Bug numbers below refer to `docs/bugs/`; the two BUG-026 records are
distinguished explicitly.

**Already preserved** means the stated, bounded behavior has an identifiable
current implementation and matching test assertions. It does not certify
live gameplay, later producers or model retirement. **Needs migration** means
useful behavior/tests exist but the replacement library still needs to own
the operation. **Uncovered** means the cited requirement lacks a directly
matching test or its correctness remains unresolved in the inspected path;
it is not proof that the present game reproduces the old symptom. Named tests
are the registered CTest names unless a test filename is given.

The user's DT-12 direction permits the entire M series to proceed without
the missing historical user save. Use same-input NEW self-oracles,
frame/audio comparisons, zero replaced-model census and stability checks;
memory remains advisory. Existing PCSX2 pins listed below are historical
coverage references, unchanged and excluded from this wave's acceptance.
Carry their applicable behavior into independent OLD-bug/self-oracle tests,
not new PCSX2 comparisons. Build replacement
fixtures from owned inputs, source contracts and available assets. Future
playtesting supplies additional scene coverage, not permission to postpone
known completion, lifetime or error-handling requirements. DMAC/VIF/GIF,
IOP/STREAM and the IPU command interface remain scaffolding to retire.

Several OLD conclusions must remain qualified:

- `L:CAVERN_MIPSRC_IMPL.md:234` proves the allegedly different coarse-mip
  payloads are identical per tile and authored offline. The remaining
  arrangement change was game re-binning; no corruption fix shipped.
- `L:CAVERN_BUDGET_IMPL.md:332` falsifies a budget explanation for the wall
  band; `:527` records approval of a bounded fix while explicitly saying the
  requested zero-artifact gate was not met. Preserve logical time and
  liveness, not the tuned base/step constants as a visual specification.
- `L:CAVERN_WALLNOISE_IMPL.md:259` separates the proven quantization defects
  from the unproven user flicker. `L:CAVERN_MOTION_IMPL.md:122` adds filtering
  beyond the authored mip chain; it is an enhancement choice.
- BUG-058/061 are known baseline-compatible mistakes. BUG-080's title
  attribution is superseded by BUG-081/084. BUG-005's sound-root/closure
  wording conflicts with OLD's later save-select diagnosis. This audit
  records those conflicts without editing the historical catalog.
- `L:SOUND_P9_IMPL.md:108` and `L:E2_SAVE_REVIEW.md:92` explain limitations of
  particular old state files. They do not justify recreating broken saved
  hardware state or waiting for replacement saves before implementing the
  library contracts.

Parent priorities: **B2** is a known default-path correctness debt, **S1**
needs a chunk-lifecycle fixture beyond ordinary FIFO reads, **I4** must not be
closed using the obsolete sound diagnosis, and **A1/A2** need whole music
transition tests. **G2/G3/G7** are the highest-risk rendering cutovers:
existing backend checks must follow the actual new producer, and known OLD
state leakage must not become intended material behavior. **I2** is a small,
independent input task with a concrete source-level failure mechanism.
These can proceed without runtime saves and without duplicating the other
workers' implementation work. Later full-game playtesting is still needed;
this audit does not establish coverage of every level, material, effect,
device, storage failure or possible gameplay sequence.
