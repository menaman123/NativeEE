### 0.2 Sequencing deviations from the construction brief (D-SEQ)

The brief's phase list is kept except where a phase's HARNESS CLAIM would depend on a
later phase's module (review finding, 2026-09-26). Each deviation is motivated by what
the `mem.mhash` lane depends on (RAM + SPAD + meta arena at the SyncV boundary):

| # | Deviation | Rationale |
|---|---|---|
| D-SEQ-1 | **SPU2 core (`sound/{sound_core,voice,vag_decoder,mixer,fmv_stream,bank_ledger}`), `sound/hle` (libsdr, sdr_remote), `pad/hle` (scePad protocol + libpad rows) and `mc/hle` (libmc rows) move from Phase 7 to Phase 4.** The host DEVICE halves (`platform/sdl/audio_sink`, `platform/sdl/input/*`, gamepad/kbm backends, `default_bindings.ini`) stay in Phase 7 | STREAM.IRX/sdrdrv (Phase 4) read SPU2 voice state (NAX/ENDX/ENVX) and write RAM from it; the per-frame pad buffer is written by the EE-side libpad HLE; the boot's memory-card check goes through libmc. The SPU2 is an IOP-bus device driven by IOP code — Phase 4 is also its natural home. | D-SEQ-3 | Phase 7 becomes "ipu/FMV + host device backends (audio sink, input backends) + play-mode audio" | consequence of D-SEQ-1; FMV (ipu + pss demux + fmv pacer) is what closes the coldboot leg's lanes (intro FMVs) |

## 1. Transplant rules (binding for every phase)

1. **Source of truth per file = `docs/filemap/INDEX.md`** (386 rows → 602 OLD files;
   destination, shape, flag tally, hack count) with row detail in the nine
   `FILEMAP_*.md` shards. A module may be written only if its INDEX row names the
   destination; a file with no row is not transplanted (§1.4 completeness rule).
2. **Flag outcomes are applied while writing** (FLAG_LEDGER master table, 553 rows =
   541 + 12 dated additions; 197 NORM / 33 SETTING / 106 DIAG / 40 TEST / 176 DELETE /
   1 NEW):
   - **NORM** — only the winning arm is written. Winner = the FLAG_LEDGER outcome
     (peak configuration: run_play.sh CANON + default-ON proven fixes, ledger
     "PEAK CONFIG BECOMES NORM"). The losing arm, the latch, and every mirror latch
     do not exist in NEW.
   - **SETTING** — a `Config` field with the PEAK default (FLAG_LEDGER "SETTINGS"
     table; ARCH §4.8 schema). The `getenv` dies; `core/config` is the only reader.
   - **DIAG** — the mechanism lands in `core/diag` behind `PS2R_DIAGNOSTICS`
     (compile-time). Release builds contain no trace of it. Probe *sites* keyed on
     game addresses/scenes are NOT transplanted (HOOK §3.1: 195 DIAGNOSTIC rows delete).
   - **TEST-ONLY** — survives only under `tests/` or `verify/` (harness channel).
   - **DELETE** — var, gate and subject code are not transplanted.
3. **One class per `.h`/`.cpp` pair** (ARCH §13; `tests/lint/lint_one_class.py`
   from day one, hard from Phase 1). No textual `.inc` includes of hand-written code;
   headers are declarations only; `.inl` only for templates.
4. **No session tags** in identifiers, namespaces, file names or comments
   (`\[[A-Z0-9-]+\]` is rejected by `lint_one_class.py --tags`). Provenance goes in
   the per-directory README (one link per record), never in code.
5. **No game constants in `engine/`** (`tests/lint/lint_engine_purity.py`, A6 §1.2
   regex set: EE text-range literals 0x100000–0x20FFFF, `FUN_`/`func_00xxxxxx`, the
   VRAM base constants, game strings, VU1 program stamps). The count is 0 from the
   first commit and stays 0 — there is no "trend to zero" because nothing game-bound
   is ever written under `engine/`.
6. **Workarounds are transplanted as quarantined, ledgered modules, not fixed on
   the way in.** The peak configuration includes them (they are unconditional in OLD),
   so byte-identity requires them. Each lands under
   `games/<title>/hle/workarounds/<name>.{h,cpp}` (title-bound
   because every one keys on a game address) with its HOOK_RECLASSIFICATION row in the
   README; retirement is a separate, later, §7-protocol step (Phase 8/9 ledger work).
   Exception — the 243 manual/anim body addresses (HOOK §3.2): NOT transplanted; the
   v2 output body runs instead, and each address is adjudicated when its code path is
   first exercised (§5.3 "adjudication ledger").
7. **OLD is read-only.** Its sources are opened read-only; its binaries
   (`build/host_app/host_app` md5 `80e3689a9e376263003dcd9c45fae83f`,
   `build-v2/host_app/host_app`, `build-v2-nog/recompiler_tool_v2`,
   `build/tests/{gs_replay,vu1_replay,vif_replay,drawlist_tool,test_*}`) run bounded
   (`verify/run_bounded.sh` — OURS, wall + RSS + progress kill) as oracles. No
   `cmake --build`, no `git`, no deliberate file write under OLD — ever. Known OLD
   defects (BUG-026, BUG-038, P4FIX-F1) are construction work items here, never fixes
   there.
   **Accepted side effects** (REFERENCE_FREEZE "Accepted side effects", same list):
   the OLD `host_app` chdirs to its own project root on startup (`main.cpp:4976-4979`)
   and, per run, rewrites the GITIGNORED `logs/cpu_diag.txt`, `logs/ring_exit.rlog`
   (and `logs/runtime_log.txt` when `PS2_LOG` is not 0 — the profile sets 0); at STARTUP
   it bundles any leftover `logs/crash_report.txt` from a previous play-mode quit into a
   gitignored `bug_reports/<UTC>_crash/` (~43 MB; BUG-039 — OLD's `~IopKernel` aborts
   under `exit()`; bench legs `_Exit(0)` and leave no report). It would also
   rewrite the TRACKED `bench_report.json`; `verify/run_leg.py` therefore always passes
   `--bench-report <leg dir>/bench_report.json` (absolute; `bench::ParseArgs` resolves it
   before the chdir) — verified 2026-09-26 (§2, "redirect probe"). The frozen
   recompiler tools have CWD-relative side effects and INPUTS (§A.1): they are only ever
   run from a NEW-side scratch directory.
8. **No copied license text.** PCSX2 (GPL) and OpenGOAL (MIT) inform the design
   (ARCH §2, paraphrased); no code or license header is copied from either. The two
   vendored PCSX2 headers OLD carries (`common/Pcsx2Types.h`, `Pcsx2Defs.h`) are NOT
   transplanted: `ee/cpu/cpu_state.h` is rewritten with our own typedefs and the same
   layout (layout proven by the savestate cross-load gate, §5.3). The xxHash-derived
   XXH64 in `render.h` is replaced by our own implementation of the published
   algorithm (`core/hash`), verified against the reference vectors in `tests/core/`.
9. **Every phase is RUNNABLE and TESTABLE against OLD.** A phase ends with (a) unit
   tests, (b) the named harness lanes/legs IDENTICAL against `verify/baseline/`
   under the cross-engine contract (§2), (c) `LintOneClass` + `LintEnginePurity`
   green over the whole tree, (d) its README rows filled. Partial lanes are the
   rule before Phase 8 (mem lane at boot in Phase 3, frames lane in Phase 6, audio
   lane in Phase 7); Phase 8 is the full 12-leg × 3-lane battery.
10. **Divergence handling is fixed:** a lane divergence is either (i) a construction
    bug — fix NEW; (ii) a bug in OLD — EQUIVALENCE §7 accepted-difference protocol
    (record first, delta isolation, bounded magnitude, N× re-proof, invariant test,
    ledgered re-freeze of the affected legs into `verify/baseline/ACCEPTED.md`); or
    (iii) a workaround retirement — HOOK §4 ladder (the workaround stays transplanted
    until the ladder passes). The OLD binary is never patched, so a re-freeze is a
    documented derivation from OLD streams, never a re-capture.

defect in the generator: before Phase 9.1 that means pulling the tool transplant
(verbatim, no IR) forward (R3); after it, a fix in `tools/recompiler` with a golden diff.

python drivers under `tests/oracle/`.

5.5 **Documentation per phase**: `docs/phases/PHASE<N>_PLAN.md` before, `PHASE<N>_IMPL.md`
after (quoted command lines, quoted gate output, ledger deltas); every root-caused
defect adds/updates a `docs/bugs/` entry in the same change; every new directory has a
`README.md` (purpose / belongs / does-not-belong / OLD provenance links).

5.6 **Deterministic profile is the only gated configuration**; play mode is checked by
recorded human runs and by the realtime-neutrality list of PHASE0_IMPL §12.1, never by
hashes. Mods-off is the only certified configuration (EQUIVALENCE REV2 (a)).

5.7 **Divergence escalation** is EQUIVALENCE §5, with the OLD side of every step run
bounded on the frozen binaries: savestate drops (`--state-every`), `.gsdl` windows via
