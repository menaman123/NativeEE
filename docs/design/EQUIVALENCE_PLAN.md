## 1. What "identical" means (the contract)

1. **Frames**: bit-identical presented framebuffer hashes at **native scale
   (scale=1)** under the deterministic profile, frame-for-frame over every anchor
   leg. Scale=1 is the contract because the current pipeline is already cmp-proven
   byte-identical at scale=1 ([GE1]) and GPU rasterization differences don't exist
   when both binaries run the same backend on the same machine.
2. **Scale>1 / interp / enhancement paths**: NOT bit-gated. Adjudicated per the
   accepted-difference protocol (§6): bounded per-channel deltas, changed-frame
   set explained, N× determinism re-proof — the BASELINE.md re-freeze discipline.
3. **Audio**: bit-identical mixed-output ring hashes per 100 ms window under the
   deterministic profile (new lane — nothing exists today, A5 gap #2).
4. **Memory**: equal RAM/scratchpad/meta-arena checkpoint hashes at savestate
   quiescence points every N frames, and byte-identical savestate section payloads
   (modulo wall_ms header field).
5. **Corpora**: gs_corpus replay hashes equal; VU 3,293+126 compare gates bit-exact;
   VIF replays bit-exact; recompiler oracle sweeps clean.
6. **Savestates**: every OLD-written anchor state loads in NEW and produces the
   same forward hash stream as OLD from that anchor (states as crossing points,
   A5 §7.3.8).
7. Anything a human can perceive that hashes can't see is covered by the pixel
   anchors: cold-boot luma gate on every leg (the black-boot lesson: 4 days of
   passing exit-code anchors over a 100% black screen, A5 §4).

## 2. The deterministic harness (`verify/`)

Composition of existing assets + the A5 §7.3 build list. Headless, scripted,
two-binary.

```
verify/run_leg --binary <exe> --anchor <state.ps2st | coldboot> --frames N
               --inputs <rec file> --profile deterministic
               --out <leg dir>
Produces per leg:
├── frames.fhash      # per-present FNV of the native-scale framebuffer (in-process,
│                     #   cheap enough for every frame; PPM path retained for debug)
├── audio.ahash       # mixer-output ring hash per 100 ms
├── mem.mhash         # RAM/SPAD/META hashes at quiescent boundaries every 60 frames
├── run.meta          # build id, GL renderer string, config fingerprint (env_ps2-style),
│                     #   suite cost — stamped and ASSERTED on comparison
└── (on request) drawlist .gsdl window, savestate drops every K frames
verify/diff_legs A B  # first divergent frame/window + escalation hooks (§5)
```

Required new pieces (all small; every requirement maps to an existing asset or a
named A5 gap): in-process frame-hash mode; input **recorder** (playback grammar
`PS2_PAD_SCRIPT` already exists — record live pads into the same grammar so human
play becomes a replayable leg — [REV3 2026-09-23 D9] this recorder is
`core/triage/InputLog`, one implementation serving both the harness and the
capture bundles); audio ring hash; headless present (gs_replay
already runs GL offscreen; host app gains the same); memory checkpoint dumper
(savestate writer already computes section CRCs — reuse).

## 5. Divergence escalation ladder (all pieces exist; the plan wires them)

On first divergent frame N of leg L:

1. Auto-load the nearest savestate drop (N−k) in both binaries.
2. Re-run the window with the drawlist recorder armed (`.gsdl`, verts+pixels ON).
3. `gs_replay classdiff --seq old.gsdl new.gsdl` → first differing draw class/order;
   `drawlist_tool diff --frame` → first differing draw record/vertex.
4. If the diverging draw is VU1-produced: capture the case at the window
   (`PS2_VUTRACE_CAPTURE` equivalent) → `vu1_replay --compare/--hle` pins the tier.
5. If upstream of VU (VIF/DMA): `vif_replay` on the captured chain.
6. If CPU-side (game logic): memory checkpoint bisect between boundaries, then the
   recompiler oracle on the implicated functions; PCSX2 breakpoint-walk forensics
   remain the manual court of last resort (as today, A5 §5.2).
7. Every localized root cause becomes a permanent test at its layer.

## 7. Accepted-difference protocol (when a difference is a bug in OLD)

The audits already flag candidates: CT16 decode ignoring TEXA while CT24 applies it
(A3 §2), the CSM2 linear-only scope cut, this month's OLD-tree fixes landing during
migration (MIGRATION R11). A difference is acceptable ONLY with all five:

1. **A record** stating the hardware-truth argument (GS manual/ps2tek/PCSX2
   behavior) and why OLD is wrong — written before the change lands.
2. **Delta isolation**: a temporary compatibility switch in NEW (test-build only,
   not a shipping gate) or a quantified bound proving the changed-frame set is
   exactly the scenes engaging the fixed path — the [S107]/[S111] proof shape.
3. **Bounded magnitude**: per-channel deltas quantified per anchor (the [WN4] ≤ one
   5-bit step precedent).
4. **N× determinism re-proof** on the new baseline (2–3 separate processes).
5. **A new invariant test** pinning the corrected behavior, and baselines re-frozen
   via the ledger (append to the BASELINE.md-style freeze history — the A5 §2.2
   ledger continues, zero unexplained drift remains the standing property).

OLD-tree hotfixes during migration follow the same protocol in reverse: the fix's
record + test port forward, and the NEW baseline captures it before the phase gate.

**Masks — a MASK decision in code.** A §7.1 row whose decision is MASK becomes one or more
lines of a mask file consumed by `verify/diff_legs.py --mask-ranges FILE` (today
`verify/mask/coldboot_elf_text.ranges`), grammar `0xLO-0xHI  <ROW-ID>  # why` (HI exclusive).
The rules that keep a mask from ever becoming a way to hide things (I5.1-H, user decision 2):
(a) **a mask range is never added without a §7.1 row** — `<ROW-ID>` is mandatory on every line,
matches `^P[0-9]+-[A-Z0-9][A-Z0-9-]*$` and must head a row of a §7.1 table here or in
`docs/phases/PHASE*_PLAN.md` / `PHASE*_IMPL.md`; a line whose row does not resolve is a usage
error (exit 2) naming the line, and the mask is not applied; (b) a range lies in RAM0
(`0x0-0x2000000`) or in the scratchpad (`0x70000000-0x70004000`, image offset `addr & 0x3fff`),
and **the only scratchpad bytes a mask may cover are the boot stack's 13 dead words
`0x70003ef0-0x70003f44`** (HI exclusive; the same 13 words PHASE4_IMPL :942 and user decision 2 write
word-inclusive as `0x70003ef0..0x70003f40`; `SPAD_MASK_WINDOW` in `diff_legs.py` — one constant,
changed only by a new decision on this record); the META arena is never maskable; (c) **every verdict line carries
the masked byte count per lane** — `IDENTICAL-UNDER-MASK (masked RAM0 1940968 B, SPAD 84 B,
META 0 B)`, a plain run prints `masked 0 B` — and the report lists each range with its lane,
size and row; (d) masking is symmetric (a leg against itself is IDENTICAL-UNDER-MASK with equal
counts) and is applied at compare time only: the frozen baselines are never edited. The verdict
word under a mask is `IDENTICAL-UNDER-MASK`, never plain lane identity.

**Frames-lane pairing — by key, coalesced presents reported, the FMV window by picture (DP-9 (a)+(c),
DP-12 (a); user decisions 2026-10-01 19:19).** `frames.fhash` lines are `<key>,<hash>`; `verify/diff_legs.py`
pairs them BY KEY, never by line index. (a) OLD's graphics thread skipped a present when the next queued job
was also a VSync (`graphics_thread.cpp:3085-3094`), so an OLD leg carries one line per PRESENT and lacks the
keys of the coalesced presents (coldboot keys 64, 65, 420, 421, 619, 966); NEW writes one line per boundary.
When exactly one leg of a pair is `tree=legacy`, a key that leg lacks inside its key span is a **coalesced
present**: skipped, listed in the report (`frames.fhash: coalesced presents (keys the A leg lacks …): 2 -- 64,65`)
and counted on EVERY verdict line (`…, coalesced N`; a plain run prints `coalesced 0`), so a skipped key is
never silent. Between two legs of the same tree a missing key on either side is a divergence (the admissibility
self-diffs stay strict). Hash values are never tolerated: the first shared key with different hashes is the
first divergent frame; different last keys are a length divergence. (c) NEW keys its lines by the original's
vsync-frame convention: a cold boot `1, 2, 3, …`; a restored leg keeps key 1 for its first present and continues
from the anchor's vsync frame, `restored_vsync_frame + 1, + 2, …` (OLD `savestate.cpp:2182` reseeds the
graphics thread's frame counter from the file; `graphics_thread.cpp:2279` increments before the present; the
boot-era present before the load stays key 1), so one anchor's lines carry the same keys in both trees
(`verify/baseline/artdet_f37152/frames.fhash`: `1, 37157, 37158, …` with `restored_vsync_frame=37156`).
(DP-12) The FMV window cannot be paired by frame hash: the title's whole-movie demux loop raises no frame
boundary in NEW while OLD free-ran ≈1100 wall-clock presents, both non-hardware cadences. With
`--fmv-pictures <manifest> [--fmv-window-legacy LO-HI]` the window is EXCLUDED from the by-key pairing on
both legs (the legacy leg's window is declared on the command line from its baseline — coldboot `172-976`:
the hold frame `0x3473b62d15ba180c` ×216, movie 1, the splash, movie 2, the splash; the NEW leg's from its
own census `fmv_window=<first>-<last>` boundaries, the boundaries at which the Verify slot found pictures served
since the previous one), the keys ABOVE the window pair by ORDER (the n-th post-window line of each leg), and
the window is declared **`frames: FMV window PAIRED-BY-PICTURE (547/547, plane-check 2/2 movies)`** only when
(1) the NEW leg's `fmv_pictures_served` equals the manifest's `served_total` and row count — the manifest
being the `FmvPictureOracle` golden (`tests/ipu/fixtures/coldboot_pictures.sha256`, OLD's 547 served pictures
as P6 sha256, proved against the movie files offline by the ctest) — and (2) the plane check,
`<leg>/fmv_plane_check.txt` (`movie<N> boundary=<b> plane=0x<addr> picture=<k> strips_exact=<n>/<total>` per
movie: the leg's `--state-every 1` image at a serve boundary holds the golden picture laid out by
`FrameWriter::WriteRgb32Strips` at the title's RGB32 plane, EVERY strip bit-exact — no tolerance), covers every
movie of the manifest. Anything less prints `frames: FMV window NOT PAIRED (<served>/<total>, plane-check
<m>/<movies> movies): <why>` and the lane is divergent.
