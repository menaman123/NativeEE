## 1. Order and stopping rule

Serial, **4 → 5 → 6 → 7**, one lane gate at a time; a phase's integration is not started until the previous phase's gate
is green or its residual is a recorded, sink-attributed row (CONSTRUCTION `:490-500`: a divergence NOT attributable to a
listed sink is a construction bug and blocks). The order is forced by the data: Phase 4's memory lane cannot get past
boundary 0 without Phase 5's VU0 micro (the `vcallms 0xf0` park, PHASE4_IMPL HANDOFF item 2), Phase 6's frames lane needs
Phase 5's arbitrated GIF stream, Phase 7's IPU FIFOs hang off Phase 5's DMAC ch3/ch4.

Every item below names its **owner file(s)** and the **gate that proves it** (CONSTRUCTION §4.N). Gate commands are the
harness's (`verify/run_leg.py`, `verify/diff_legs.py`, `verify/battery.py`; bounded through `verify/run_bounded.sh`);
baselines = `verify/baseline/<leg>` (12 legs, frozen). Rules in force: STAGE_RULES.md (bounded runs, `-j4`, no OLD
edits/builds/git, helper scripts as files under `/tmp/<stage>/`), the accepted-difference protocol for any OLD-wrong finding,
`docs/bugs/` for root-caused defects.
