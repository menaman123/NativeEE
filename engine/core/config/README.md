# `engine/core/config/`

**Phase:** 1  
**Purpose:** THE Config schema (38 fields, ARCH §4.8), ini/CLI loader, validator (explicit dependency DAG), the `deterministic` preset.

## Belongs here

- Config (struct), ConfigLoader, ConfigValidator, DeterministicProfile; the ONLY place that may call getenv (dev builds, PS2R_SET blob)

## Does not belong here

- any getenv elsewhere; per-subsystem knobs that are not in FLAG_LEDGER's SETTINGS table

## Transplanted from (OLD, read-only)

- `main.cpp (CLI + ini), display_settings.{h,cpp} + display.ini, scripts/run_play.sh CANON defaults, verify/profile_deterministic.py`

## Flags applied

SETTING rows are single-sourced: `docs/filemap/settings_table.tsv` (generated by
`tools/gen_settings_table.py` from `docs/filemap/FLAG_LEDGER.md` SETTING rows + `PHASE1_PLAN.md` §3;
59 rows == `Config::Keys()`, checked by `Coretest_config_schema` + `SettingsTableReproducible`).

## Rules

- One class per `.h`/`.cpp` pair (`tests/lint/lint_one_class.py`); headers declarations-only; no `.inc` includes.
- No session tags in identifiers or comments; provenance goes in this README as links, never in code.
- Flag outcomes applied at transplant time (NORM winning arm only / SETTING = Config field / DIAG = core/diag / DELETE+TEST-ONLY not written).
